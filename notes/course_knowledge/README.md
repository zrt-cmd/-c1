## 查询

在工作区根目录执行，例如

```bash
python3 notes/course_knowledge/search.py "回环" --course exp004-slam-navigation
python3 notes/course_knowledge/search.py "手眼" --course exp005-robot-arm --full
python3 notes/course_knowledge/search.py "播报" --course exp002-speech-interaction
```

查询结果显示原文 URL、章节锚点、本地文件和原文上下文。多个关键词需要在同一章节出现。也可直接搜索 text/ 中全部正文。

## 使用约定

1. 回答项目问题时先检索原文，再检查本地代码或真车实际配置。明确标注“教程记载”“代码核对”“现场日志”和“推测”。
2. 区分 C1、B2、LZ-XL01、LDT-01、G1、Go2。设备、串口、话题、模型路径、时间和性能数字不得跨平台直接套用。
3. 网页里的目标、演示、预计指标、规划内容和代码实现是不同证据。网页写有“已验证”时，表述为教程作者的记录。
4. 找不到的接口、建设中页面、404 附件和未提供的源码必须指出缺口。参数默认值也要标明来自哪个版本。
5. 归档覆盖全部实验入口。人工核读聚焦原理、接口、实操与排错，未逐项运行硬件实验，图片及交互行为也未全部人工验读。查询具体问题时读取对应章节全文，避免靠摘要补细节。
6. 本地文件用于跨会话检索。下次对话需要重新读取索引或对应章节，不能承诺模型永久记住全部内容。

## 文件结构

- html/ 原始 HTML，包括内嵌脚本和示例。
- text/ 去除脚本与样式后的可检索正文，每页头部记录来源和日期。
- assets/ 成功获取的同站点图片、样式、脚本等。
- pages.jsonl 正文章节、锚点和代码块的结构化提取。
- manifest.json 每个已请求 URL 的结果、错误、字节数和 SHA-256。
- references.json 页面引用关系，含外链。
- sync_courses.py 重新抓取公开站点并更新基础索引的脚本。重新抓取后还需重新核对课程统计与笔记。
- search.py 基于原文的只读查询工具。

原作者页面为原始材料，本站点快照仅供项目学习与溯源。
