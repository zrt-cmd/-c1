💡 本节要点
情绪 ≠ 关键词命中。情绪分布在
两个通道
：文本说"内容情感"，语音说"当下状态"。两条通道都到齐，才能接近人类的"听话听音"。
这套"多通道并行、汇入统一大脑"的思路在多模态模型里已经落地——下图是视觉语言模型（VLM）的两条输入路线：纯文字直接进语言模型，图片则先经预处理与视觉编码器提取特征，再与文本一起汇入语言模型生成回答。本实验把同样的架构换成"文本 + 语音韵律"双通道：
图 1-1：多模态输入的两条路线 —— 路线① 纯文字 prompt 直接进入语言模型（rkllm · NPU）；路线② 上传图片先经预处理（补边到 448²）与视觉编码器（rknn · NPU）提取 196×2048 图像特征，再与文本汇合生成回答。与本实验同理：多一条通道，就多一份"言外之意"的证据。

看酒标成分表
文本情绪通道
对 ASR 文本做六分类：积极 / 消极 / 中性 / 愤怒 / 开心 / 悲伤。入门用情感词典（"太棒了"+2、"烦死"-2），进阶交给 NLP 分类器。

两条通道各出一个分数，加权合并：置信度高的通道话语权更大；或决策级——两通道投票一致才输出。

语音通道的三个特征怎么算（都是"每句话一段统计量"）：
特征
生活读法
典型信号
基频 F0（音高）
嗓音"往上翘"还是"沉下去"
均值升高 + 起伏大 → 激动/愤怒；压低变平 → 悲伤/压抑
音量 RMS（能量）
说话"多大声"
持续偏高 → 愤怒/兴奋；骤降 → 失落
语速（字率/停顿）
说得多急、停多久
字率高停顿短 → 焦急；字率低长停顿 → 低落或迟疑
🎯 核心直觉
文本通道擅长"判类别"（哪个词刺痛了人），语音通道擅长"判强度"（此刻有多上头）。融合 = 用文本定性、用韵律定量。
03
关联知识点
📝
文本六分类
积极 / 消极 / 中性 / 愤怒 / 开心 / 悲伤。可用情感词典+规则打分入门，也可接 NLP 分类器或让 LLM 按标签白名单输出。
🎵
韵律三件套
基频 F0、音量 RMS、语速/停顿——从波形直接统计，不依赖语义；对录音增益与麦克风距离敏感，需归一化。
📐
效价-唤醒度坐标
横轴效价（负→正），纵轴唤醒（低→高）：开心=(+,高)、愤怒=(−,高)、悲伤=(−,低)、平静=(中,低)，把离散标签连成连续空间。
🔗
双模态融合策略
分数级加权（w·text+(1−w)·voice）或决策级投票；冲突时（反话、反讽）可提高语音通道权重或标"低置信"交给人。
🗣
情绪感知的下游
情绪标签随 context 进 LLM，让回复语气随之调整；TTS 端呼应 EXP-03 的 --speed/音高参数改变播报风格。
💼
应用场景
情感助手（陪伴、提醒时察言观色）、智能客服（升级投诉预警、安抚话术切换）——情绪是服务类机器人的核心 KPI。

通道置信度
动态调 w——文本含明确情绪词时信文本，文本空泛（"哦""嗯"）时信韵律。

09
重点与易错点
⚠️ 高频故障
情绪是最"软"的任务，坑不在报错而在
悄悄出错
：增益没固定、基线没归一、标签不平衡——四条通道全绿但主观准确率很差时，先查下面这张表。
现象
原因
解决
音量特征全部偏高，区分不出愤怒
录音增益/AGC 每次不同
固定 amixer 增益采样；RMS 用相对说话人基线而非绝对值
"我没事"类逞强句全判中性
只用文本通道
文本空泛时提高语音权重；冲突即降置信并按韵律裁决
反讽"太棒了……"判成开心
词典无语气感知
结合降调/拖长（F0 下滑、语速↓）触发反讽规则或交给 LLM 综合裁决
否定句情感翻转错误（"不喜欢"）
词典未处理否定窗口
否定词作用域覆盖其后 2-3 个词；双重否定取反后再取反
愤怒/开心召回极低
样本六类不平衡（中性占多数）
每类等量采样；评测用 per-class 召回而非整体准确率
远近说话人分数不可比
F0/能量未归一
按说话人做 z-score 归一，或会话首轮先"校准 5 秒"采基线
标签接进 LLM 后回复更怪了
system prompt 冲突或标签写错位置
情绪标签放 messages[0] 人设之后，限定语气指引而非硬性台词
先做
单通道各自可信
的评测，再谈融合——融合救不了两个都不准的通道。
每个测试句固定"文本 + 波形"成对存档，回归测试时两通道一起复跑。
输出永远带
置信度
；低置信交由澄清话术（"听起来您有点着急，是吗？"）比硬猜更稳。
别忘了闭环：情绪的最终消费方是回复语气与 TTS 风格，而不是一张打印的表格。
