两张皮：发与收分开
• 你敲的每个命令都走「组帧 → 串口线」一条下行路
• 接收线程独立跑，0x08 状态帧和应答帧分流，互不阻塞
save 为什么有数据
• 你没发过读指令，但下位机一直在广播 0x08
• 线程收帧 → 最新覆盖进缓存 → save 只是取快照
出口只有一条
• save 的动作只活在内存列表，退出即丢
• yaml 导出 + colcon build 才交到 EXP-05 手上
