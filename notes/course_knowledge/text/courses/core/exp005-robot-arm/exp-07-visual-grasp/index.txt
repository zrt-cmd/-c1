视觉动态抓取

01
问题引入
EXP-06 的坐标是尺子量的——物体一挪就抓空。要让机械臂"看到"物体，需要把一帧彩色图像变成 base_link 下的 3D 坐标，再交给你已经熟悉的 IK+抓取链路。这中间横着三座桥：
颜色桥（HSV）
：图像成千上万像素，哪些属于目标？光照一变 RGB 全乱，HSV 才稳。
深度桥（反投影）
：像素 (u,v) 只有二维，加上深度图的 d 才能还原相机坐标系里的 (X,Y,Z)。
坐标桥（TF）
：相机装在夹爪上随臂晃动，相机系的点必须实时换到 base_link 才能抓。
本实验 8 学时：一条 launch 拉起全栈，rqt 三栏盯着它看，四个人机服务管着节奏，最后拿红色物体（30~50mm）做成功率验收。
02
原理通俗讲解
HSV 分色像用"色相环"筛豆子。
RGB 是红绿蓝三盏灯的混合亮度，灯一暗全都变样；HSV 把"什么颜色（H）"、"多纯（S）"、"多亮（V）"拆开——只圈定 H 的范围，屋内灯稍亮稍暗都不影响筛选。
inRange
就是拿一个区间筛子过一遍像素，命中的涂白成掩膜。
深度反投影像"由近及远钉钉子"。
已知像素在画面偏右 100 像素、深度 0.5m：乘内参（fx≈614）一除，就知道它在相机右侧约 8 厘米、正前方半米——(u,v,d)→(X,Y,Z) 就是这一除。深度图单位是 uint16 的
毫米
，用前必须 /1000，这是最经典的翻车点。
TF 像"随军翻译"。
相机说"在我右前方 30cm"（camera_depth_optical_frame 系，X右/Y下/Z前，REP-103），底座听不懂；tf_buffer.transform 一换算，底座就知道"在base_link 前方多少"。相机装在手上，臂一动翻译表就更新——这就是 TF 的实时性。
look-then-move 是"看准了再伸手"。
观察（OBSERVE）→ 有人按确认（CONFIRM）→ 猛抓（PICK）→ 回怠速（IDLE）。光看不确认就动是鲁莽，确认了快动是果断——五态循环把二者拆开。
形态学开闭
先擦后补的橡皮擦
开运算（先蚀后胀，5×5 核）擦掉小噪点；闭运算（先胀后蚀）补上掩膜窟窿，让轮廓完整。
安全熔断
面积 < 100 像素不抓
轮廓太小按噪声处理，宁可 skip 也不夹空气——防误抓的第一道闸（源码实际阈值 100；想更稳可自己提到 500）。

动画讲解：观察—确认—抓取三乐章
RGB + Depth @ 相机
HSV mask → 质心 (u,v) → depth d → (X,Y,Z)
TF→base_link
源码 11 态：IDLE→INIT→OBSERVE→…→PICK→DONE
start → 检测(绿) → 等 confirm(黄) → 抓取(红) → 回位(蓝)
9 秒一循环：看（observe）→ 报坐标 → 等人点头（confirm）→ look-then-move 抓取 → idle
动画 9 秒一循环：左框里绿色虚线框住红色目标并提取质心，经 TF 换算到 base_link；右上状态机光点在 OBSERVE(绿)→CONFIRM(黄)→PICK(红)→IDLE(蓝) 间移动；下方机械臂在 PICK 段伸出、合爪、带物回位——"看准了再伸手"的节奏一目了然。

# 步骤 3 · 反投影自测（内参请从 camera_info 读，别写死）
ros2 topic echo /ascamera_hp60c/camera_publisher/depth0/camera_info --once
# 看 k[0]=fx、k[4]=fy、k[2]=cx、k[5]=cy；实测 ≈614/614/320/240
# 手算：u,v=320,240 → X=Y=0（正好光轴中心），Z=d/1000；偏 200px、d=0.5m → X=(200)*0.5/614≈0.163m
# 标定物实测：1m 距离误差预期 ±2-3cm；超差先查 camera_info 是否已更新
# 步骤 4 · TF 链与时序
ros2 run tf2_tools view_frames
# … → arm_link4 → … → tcp_link → camera_depth_optical_frame
ros2 run tf2_ros tf2_echo base_link camera_depth_optical_frame
# 步骤 5 · 人机协同四服务（Trigger 类，命令体留空）
ros2 service call /visual_grasp/start   std_srvs/srv/Trigger "{}"
# 日志：State IDLE -> ... -> DETECT → Contour: area=…, centroid=(u,v) → WAIT_CONFIRMATION

# 确认后进 PICK
ros2 service call /visual_grasp/skip    std_srvs/srv/Trigger "{}"
# 放弃本目标
ros2 service call /visual_grasp/abort   std_srvs/srv/Trigger "{}"
# 中止回 IDLE
# 步骤 6 · 换色验收（以抓 30~50mm 红色物体为例）
# 1) 改 HSV 两段阈值：优先确保"副段 160~180"覆盖住你手里的红块（实测 H 落在 167~178）
# 2) 桌面摆放物体，start → DETECT 出轮廓 → confirm → 看 PICK 是否 <8s 完成
# 3) 拿走物体再 start：轮廓面积 <100 应被熔断（"Largest red contour too small"）→ 不抓空气
# 4) 免确认直连（首次务必先过一遍带确认的）
ros2 launch car1_app visual_grasp.launch.py wait_for_confirmation:=false
# 安全预演：只定位不抓，机械臂只升到观察位
ros2 launch car1_app visual_grasp.launch.py dry_run:=true
# 验收指标：HSV 检测成功率>95% · 单周期<15s · 抓取成功率>85% · 误抓<5%

让节点

：拿卷尺量一下物体实际位置，和日志里的坐标比对，差了 3 cm 以上就别急着抓，先查内参/深度/TF，否则你会在"抓偏"和"到底哪一步偏"之间反复折腾。
