EXP-02
PWM 舵机
脉宽 500~2500 μs，中位 CENTER_PWM=1500，弧度换算 PWM_TO_RAD = 4.712 rad ÷ 2000 = 0.002356。舵机物理行程 270°=4.712 rad，对应 ±1000 μs =
±2.356 rad = ±135°
（这才是实机真正的限位）

SAFETY FIRST
动手前的四条安全红线
机械臂是全课程唯一会"真动"的执行器，越界代价是舵机堵转打齿、甚至拽倒自身。以下红线在每个实验第 09 节还会以坑表形式复现。
PWM 一律落在 500~2500 μs 之内
——发之前先心算对应角度，超限即撞机械限位。
目标位姿必须逐步逼近
——先小步试、再放大步长，禁止一条指令甩到极限位。
抓取前先预演
——用 pwm_to_fk_demo 或 Web 仿真器把 5 路 PWM 走一遍，确认不会撞桌再上真机。
先跑安全前置脚本
——test_servo_direct 自检通过、串口权限（dialout 组）配好，才允许进入交互模式。
LEARNING PATH
学习路径建议
先比喻，后公式
每个实验的"原理通俗讲解"先用生活类比（手臂、暗号脉宽、反推姿势）建立直觉，再看 DH 表与 CRC8 —— 按顺序读，公式不再是天书。
软硬两条路线对照
EXP-01 是纯仿真路线，EXP-02 是裸机串口路线，EXP-05 回到 ROS2 架构路线 —— 同一条机械臂三种打开方式，对照着学最快。
动画与互动台先玩一遍
帧格式、连杆几何、抓取流程都有 SVG 动画；PWM↔弧度、FK 正解、HSV 调参都有互动台 —— 先玩懂参数，再上实机少翻车。
安全红线贯穿始终
PWM 必须落在 500~2500μs、目标须逐步逼近、抓取前先预演 —— 实机代价是堵转打齿，把第 09 节的坑表背下来再动手。
LEARNING OUTCOMES
学完你将能做什么
四个可验收的能力目标，对应三个篇章的递进路径——每一条都能在实验报告里拿出证据。
读得懂模型
看 URDF 就知道每个 link / joint 在干什么，能沿 7 坐标系 TF 链回答"末端到底在哪"，能在 RViz2 里复现并修改模型。
组得出协议帧
用 pyserial 手工拼出 0xAA55 + CRC8 的完整帧，把任意关节角换算成 500~2500 μs 安全脉宽并下发真实舵机。
算得对运动学
手算与代码双轨完成 FK 正解与解析 IK 逆解，会跑闭环验证、对照 Avg<0.5 / Max<1.5 mm 验收线，并按讲义口径归因误差（当前 18~23 mm 超差源于 IK/FK 模型不一致，而非机械偏移）。
调得动抓取
调 gripper_depth / pre_grasp_height 等节点参数，串起"预演 → 设目标 → Trigger 抓取 → 放置"全流程，并能扩展到视觉动态抓取。

FAQ
开课前的三个常见疑问
没有真机能学完吗？
能。EXP-01/03/04 全程可用 Gazebo 与 Web 仿真器完成闭环验证；EXP-02/05/06/07 的命令与协议推导可在无硬件条件下通读演练，上机步骤以真机验收为准。
为什么先仿真、后裸机？
仿真里改坏一个 URDF 只是重载，裸机发错一帧可能堵转。先在数字世界建立"关节角 ↔ 末端位置"的直觉，再下探串口与 PWM，翻车成本最低。
数学基础差怎么办？
只需三角函数与二维向量：FK=逐段累加旋转平移，IK=解一个含 sin/cos 的方程组。第 06 节动画负责建几何直觉，第 07 节互动台负责代数验算，公式不背也能算对。

BRIDGE · 通往具身智能
学完这门课，离 VLA 还有多远？
具身智能（VLA：视觉-语言-动作模型）是 2025-2026 最热的方向。它并不神秘——你在这门课里手写的每一环，正是 VLA 要"学会替代或指挥"的模块。先看清两种答法的关系，再决定往哪深造。
VLA·A
对照读法
一帧画面两条路线：手写栈 vs 端到端
本课 EXP-07 的答法
：HSV 分割 + 深度反投影 + TF 变换读懂"红色物块在哪"（感知）→ IK 与轨迹规划算出"胳膊怎么弯"（规划）→ 六阶段状态机 + PWM 把动作稳稳执行（控制）——每一环都是
人写的规则
，黑盒度低、可分段验收。
VLA 的答法
：图像 + 自然语言指令（"把红色物块装进箱子"）直接进一个大模型，输出动作序列——规则没了，换来的是
零样本泛化
：没见过的物块、没写过的指令也敢试。
逐环对应
· 感知头 ≈ HSV+深度+TF 链 · 动作序列 ≈ 六阶段抓取状态机 · 指令解析 ≈ 语音唤醒"小飞小飞"的角色升级（从关键词到语义理解）

诚实的行业站位
别急着丢掉经典栈——它是 VLA 的地基
2026 年的真实产线上，
"经典栈打底 + 学习模块增强"仍是主流
