LEARNING PATH
学习路径建议
先懂原理，再敲命令
每个实验的"核心原理"章节建议在动手前通读——知道了"为什么"，命令报错时才知道该去哪里排查。
通信机制是主轴
EXP-05~10 是全课程的脊梁：节点承载一切，话题 / 服务 / 动作 / 参数 / 自定义接口决定你的系统如何拆分与解耦。
善用交互动画
DDS 发现、QoS 匹配、TF2 坐标树这些抽象概念，先在交互沙盒里把参数调一遍，再去终端验证，印象会牢得多。
从单点到系统
EXP-17、18 两关通过后，试着把前面所有实验的节点串进一个 launch 文件、再用元包聚合起来——这就是完整机器人系统的雏形。
