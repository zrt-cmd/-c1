时间 API 与双时钟体系
IMU 200Hz、相机 30Hz，时间戳差一点数据就对不上。本课讲清 ROS2 为什么自建时间抽象层、系统时钟与 /clock 仿真时钟如何透明切换，以及 create_timer 与 Header.stamp 的正确姿势。

自建时间抽象层

回放失效
：录包回放时 stamp 是"当时录制时刻"，和新数据永远对不上
跨机负延迟
：两台电脑钟差 50ms，算出
-50ms
的"延迟"
配对失败

答案永远一致

stamp 盖在

03
原理讲解
一行调用，两套时钟，一个 bool 开关
① 调用
：想获取现在的时间戳，命令行里写
now = self.get_clock().now()
，功能就一句话——问当前的钟"现在几点"。
② now 是什么
：
now
是一个 ROS 2 时间对象（
rclpy
的 Time），里面装着
sec
（秒）和
nanosec
（纳秒）两段数值；它不是字符串，调用
now.to_msg()
就能变成
Header.stamp
那样的时间戳，直接盖到消息上。
③ 和 /clock 什么关系
：这个 now 的时间从哪来，由钟自己决定——当
use_sim_time
开成
true
时，
get_clock().now()
读的就是
/clock
话题馈进来的时间；普通模式下读的则是操作系统墙上钟。
④ 两套钟，一个开关
：系统墙上钟、仿真钟两套并存，靠
use_sim_time
这个 bool 值切换（false 用墙钟、true 用 /clock）——
你自己的代码一行都不用改
，永远只有上面那一行调用。先看框图，再看详解：
极简框图 · 一个开关，二选一
node.get_clock().now()
      │
      ├── use_sim_time = false（默认）
      │     时间源：操作系统墙钟（现实时间）
      │     特征：和现实世界一秒一秒同步，不能快进/暂停
      │     适用：真机、真实传感器（USB 相机 / IMU / 雷达）
      │
      └── use_sim_time = true
            时间源：订阅 /clock 话题
            特征：Gazebo / rosbag play 说了算——可 0.5 倍速、可暂停、可回退
            适用：仿真、录包回放

⚠️ 坑：true 了却没人发 /clock → 节点拿不到时间，死等不走（04 节实操 A）

create_timer 的真实行为与 stamp 规范
定时器原理
挂在 spin 事件循环上的周期源
create_timer(period, cb) 注册触发源；spin 每轮检查到点就把回调加入执行队列——
没有 spin 就永远不触发
，取代 ROS1 的 while+Rate.sleep()。
名义周期
回调耗时可以拖垮频率
周期只是名义下限：回调 C=0.3s > 周期 T=0.2s 时，上一回调结束下一触发点早已过期 → 实际间隔≈C，
f ≈ 1/max(T,C) = 1/0.3 ≈ 3.3Hz
，永远到不了 5Hz。I/O 密集任务要异步化。
多定时器
同节点内串行执行
demo 节点同时挂 1s 采样定时器 + 5s 摘要定时器，各自独立计时，但回调在同一事件循环里排队——一个堵全堵。
stamp 规范
盖"采集时刻"不是"发布时刻"
在读传感器的那行代码处取 now()；等处理完再盖戳，等于把处理延迟算进了传输延迟——排查延迟问题时会误导自己。
✅ 结论：定时器靠 spin 驱动、同线程串行、f=1/max(T,C)
⚠️ 风险：回调超时 → 频率被压低；stamp 盖晚 → 延迟失真
🔍 验证：02 节实测 hz≈1.000、delay=0.3ms
端到端延迟
公式：delay = 订阅端收到时刻 − stamp 采集时刻
，减去 stamp 才是"通信+排队"的真延迟。局域网有线通常 < 1ms（02 节实测 0.3ms）；多机出现
负值
说明两台电脑系统时钟没对齐——先 NTP 再查代码。

先给结论：use_sim_time 到底是什么
false → 系统墙钟（现实时间）
：读操作系统时间，跟着真实世界一秒一秒走——真机、真实传感器默认用这个。
true → 仿真时间（/clock 话题时间）
：不读系统钟，专门订阅
/clock
拿时间，由仿真器 / rosbag play 发布——可暂停、倍速、回退。
不需要"两个时间保持一致"
：同一节点同一时刻只选一套时间源，二选一，不会同时用。
对应关系
：真机实车真实传感器 →
false
；Gazebo 仿真、rosbag 回放 →
true
——你理解的这套就是标准答案；唯一强制要求是
全系统开关统一
。
一句话记住本实验
时间只有一个出口（
get_clock()
），只有一个开关（
use_sim_time
）。
凡是绕过出口直接读
time.time()

却没人发
/clock
的机器，节点一定会永久卡住。这两条覆盖了本课 90% 的故障。
