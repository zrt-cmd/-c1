02
原理讲解：什么叫"端到端平台"
课段 1 收尾 + 课段 2 · 激活旧知 · 8 min
❓ 聚焦问题（课段 1）
学员现场最常遇到的怪事：
昨天还好好的机械臂，今天开机 LeRobot 就报"找不到设备"
；把 USB 线换个口插，
/dev/ttyACM0
突然变成了
/dev/ttyACM2
。问题出在哪？带着这个故障听完全课——到课段 6 你会亲手让它永不复发。
先打个比方：端到端（end-to-end）就像
学炒菜不拆步骤
——眼睛看到菜在哪（感知），大脑想怎么抓（决策），手直接伸过去（执行），中间不留"专门算坐标的模块、专门规划路径的模块"。具身智能的端到端策略也是这样：摄像头画面直接进模型，模型直接输出关节角度。而要让这条链路跑起来，先得把三个"端"物理连好：
1
感知端
：三路 USB 摄像头（左手 / 右手 / 头部）给系统提供画面
2
决策端
：Ubuntu 主机跑 LeRobot 与策略模型，是整个平台的"大脑"
3
执行端
：主臂（leader，被人牵着示范）与从臂（follower，跟着学）通过串口听主机指挥
↺ 激活旧知（课段 2）
回忆 Linux 基础课三条旧知：①
/dev
下每个文件都代表一个设备；② 串口设备挂在
ttyACM*
/
ttyUSB*
名下；③ USB 是
热插拔
总线，内核按"谁先被枚举"发号。三条合起来，正好解释课段 1 那个故障。
为什么第 00 章要花大力气配
udev
规则？想想小区给快递柜编号：厂家给每块电路板烧了唯一"序列号"（serial），但 Linux 按插拔顺序把串口命名成
ttyACM0
、
ttyACM2
……
一重启顺序可能就变了
。udev 规则就是"贴标签"：不管插哪个口，只要序列号是
5B79018622
，系统就给它挂上
/dev/arm_master_right
这个永久别名。
03
硬件与材料
课段 3 · 示证新知 · 15 min
LZ-XL01 平台由
三路摄像头（感知端）＋ Ubuntu 主机（决策端）＋ 四条 SO100 机械臂（执行端）
组成。下表按"角色—作用—关键依赖"把三大件拆开讲：
🦾
从臂 · follower ×2
执行端 · 学你动作干活的手臂
角色：被主臂带着示范、真正去抓取/操作
从臂装在底座上（连小推车），吃 12V 大幅供电，是端到端链路里"动手"的那一只。
接口
USB 串口 · /dev/arm_slave_left / arm_slave_right
关节
SO100 六关节（Joint1~5 + 夹爪）
供电
12V 8A（重载，举东西用）
序列号
5B79019324（左） / 5B79018452（右）
✋
主臂 · leader ×2
示范端 · 你牵着它示范动作
角色：被人手掰动、编码器读出角度传给从臂
主臂装在桌面（卡钳固定），被人手推着做动作，是"示教"的源头。
接口
USB 串口 · /dev/arm_master_left / arm_master_right
关节
SO100 六关节（与从臂一一对应）
供电
5V 2A（轻载，仅示范）
序列号
5B61034506（左） / 5B79018622（右）
📷
USB 摄像头 ×3
感知端 · 端到端的"眼睛"
角色：给系统提供画面，是"感知→决策→执行"的起点
左手 / 右手 / 头部各一路，直连主机固定端口，只为让画面永远知道自己来自哪个位置。
规格
640×480@30 · YUYV/MJPG
接口
USB 直连 · /dev/cam_left / cam_right / cam_head
插口
主机背面端口 7 / 6 / 1（不可变动、不可走拓展坞）
匹配
按 ID_PATH 写 udev 别名
▍实物对照：三大件长这样（来源：LZ-XL01 硬件指导文件）
(a) 从臂 follower · 执行端（末端为平行夹爪）
(b) 主臂 leader · 示范端（带握把，人手握持示教）
(c) USB 摄像头 · 感知端
▍安装位置与接口细节：主从臂怎么装、摄像头怎么架
(d) 主臂 · C 型卡钳旋转夹紧固定桌面边缘
(e) 从臂 · 连底座卡到小推车上
(f) 头部摄像头 · 架设于垂直立柱俯视工作区
◆ 一条口诀记三件硬件
摄像头
感知看
→ 主机
决策算
→ 机械臂
执行动
。身份固定的关键字段：臂用
序列号
（serial），相机用
端口位置
（ID_PATH）——记住这两点，后面的 udev 规则就秒懂。

08
常见问题
课段 8 · 融会贯通 · 13 min
装完驱动 nvidia-smi 找不到命令
：忘了 reboot，或安装时没等 apt 完成就中断——重启后再验证
conda: command not found
：
conda init bash
后没执行
source ~/.bashrc
，或没开新终端
pip install 极慢/超时
：确认命令带了
-i https://pypi.tuna.tsinghua.edu.cn/simple
清华源参数
ls /dev/arm_* 提示 No such file
：udev 规则没重载——
sudo udevadm control --reload-rules && sudo udevadm trigger
后重新插拔臂
摄像头别名不生成
：相机必须插在规则里写死的端口（7/6/1），插错口 ID_PATH 对不上
登录组不生效
：usermod 加组后必须
注销重新登录
