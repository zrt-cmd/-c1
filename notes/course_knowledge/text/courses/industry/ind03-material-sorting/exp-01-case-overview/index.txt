02
原理：任务定义与行为克隆
课段 1 收尾 + 课段 2 · 激活旧知 · 8 min
❓ 聚焦问题（课段 1）
学员常遇到的怪事：明明录了几百遍双臂分拣示范，机器人一上真机还是不会分拣——左手伸到右边、银件丢进黑格。问题到底出在采集、转换、训练还是推理哪一段？带着这个疑问看完整课——本实验先给全局地图，后面四个实验逐段攻关。
分拣任务像教新手整理零件盒：
「左手管黑色件放左格，右手管银色件放右格」
。机器人并不理解「黑色」的含义，它只是把「看见的画面 + 当前关节状态」映射到「下一步关节动作」。我们把人的双臂示范录下来，让它反复模仿——这就是
行为克隆（Behavior Cloning）
：我做给你看，你照着学。
任务准则
抓 - 拿 - 放：左手对黑件、右手对银件，各归各格，动作连贯不交叉。
示范来源
操作者穿戴 LDT-01 遥操作端，主臂领动、从臂跟随，第一视角三路相机同步录像。
学习目标
ACT 策略学会「画面 + 16 维关节状态 → 下一帧动作」，部署回真机复现。
成败关键
桌面环境与采集时一致；数据保质保量，坏示范用「本次采集失败」按钮剔除。
↺ 激活旧知（课段 2）
回忆三件旧事：① 教小孩系鞋带是「放慢动作让他照着做」，不是讲公式——这就是行为克隆；② 工厂流水线上道工序的产物正是下道的原料——本课「采集→转换→训练→推理」四段也是这条链；③ 坏示范会被小孩学成坏习惯——所以采集时的「本次采集失败」按钮就是质检阀门。
图 1-1｜LDT-01 分拣现场：双臂机器人就位，分拣桌面、蓝色分格收纳盒、黑色/银色零件物料已摆放到位。开机（默认密码 1）后访问
localhost:8699
一键启动，进度条走完进入遥操作状态。
生活化类比：
行为克隆像「跟着大厨学切菜」——你只看大厨的手怎么动、食材在哪，不背菜谱公式；看得越多、切得越准，你越像大厨。若大厨示范里混入切到手的失误，你也会学会失误——所以
坏数据必须剔除，数据质量 > 数据数量
。

部署与开机
：摆好桌面场景 → 测量机械臂与桌面距离 → 一键启动上位机（localhost:8699）。
建任务与采集
：新建任务（名称/描述用英文）→ 预览轨迹 → 点开始后 3 秒内握持操作端完成示范 → 停止当前组，循环往复。
标记坏数据
：失误的组点「本次采集失败」，该组不计入训练。
转换与训练
：convert 脚本切段转换 → lerobot-train 训练 ACT 策略（本地或云端均可）。
推理复现
：加载 checkpoint，三终端启动 ROS2 推理，/model_ifrun 服务开关控制双臂自主分拣。
任务创建流程（4 步）：
① 点击「新建任务」→ ② 填写任务名称（建议英文，如
sort_black_left_silver_right
）与描述 → ③ 保存后任务列表出现新项 → ④ 点「1 开始」进入采集模式、「2 预览」先观察机械臂运行轨迹再正式录制。
采集界面要点：
点开始数据采集后须在
3 秒内
握持遥操作端（主动臂），画面实时显示三摄像头视图（头部 + 左腕 + 右腕），完成一组后点「停止当前组」。失误的组点「本次采集失败」，该组不计入训练。
图 1-2｜分拣物料与收纳盒：黑色零件放左侧、银色零件放右侧，收纳盒左格收黑件、右格收银件——左右手分工是本课分拣任务的核心约定。

关键命令（预览，后续实验展开）
随课段 5 / 6 对照使用
以下命令摘自《聆动机器人案例-工厂场景》与 LeRobot 0.4.1 官方入口，本实验先混个脸熟：
# ① 数据转换：save_data 目录 → LeRobot v3.0 数据集（按 episode 区间）
python convert_lerobot_v3_fixed_simple.py \
  --input  /home/lindenbot/save_data \
  --output /home/lindenbot/converted_data \
  --start 180 --end 209 --task
"Parts Categorization"
# ② 训练 ACT 策略（本地示例，完整参数见 EXP-03）
lerobot-train \
  --policy.type=act \
  --dataset.repo_id=lindenbot/parts_categorization \
  --dataset.root=/home/lindenbot/converted_data \
  --batch_size=12 --steps=50000 --save_freq=4000
# ③ 真机推理：三终端启动后，用服务开关控制自主分拣
ros2 service call /model_ifrun std_srvs/srv/SetBool
"{data: true}"
# 开始
ros2 service call /model_ifrun std_srvs/srv/SetBool
"{data: false}"
# 停止
编号提醒：
save_data 下的采集编号不从 0 开始，取「当前最大编号 = 最新一集」；切段时用
--start/--end
或
--skip
排除坏集。
这三条命令分别属于 EXP-03（转换/训练）和 EXP-04（推理）的核心操作，本实验只要求「读得懂每段在干什么」：
转换在干什么
把散装采集记录（CSV 关节角 + 视频帧）按 episode 切齐，重排成训练框架统一的数据格式。
训练在干什么
让 ACT 网络反复看「当前画面 → 人的下一个动作」，把示范内化成权重/checkpoint。
推理在干什么
真机上加载 checkpoint，把每帧观测实时翻译成关节指令，服务开关随时接管/交还控制权。
一条主线
三条命令共享同一套数据：converted_data 既是训练的读取根目录，也是排查问题的唯一事实来源。

08
常见问题
课段 8 · 融会贯通 · 13 min
Q 演示视频能正常播放吗？
源片为 HEVC/H.265 竖版 720×1280，Chrome/Edge（Win）自带解码一般可直接播；若黑屏请换 Edge 或本地播放器打开同目录 mp4。
Q 上位机打不开？
先确认一体机一键启动完成、进度条 100%，浏览器访问 localhost:8699；默认密码 1。
Q 左右手会「串」吗？
采集时就固定分工：左手黑件左格、右手银件右格，不交叉；训练数据才有一致的映射规律。
Q 四段顺序能跳吗？
不能。没有合格的采集就没有可转换的数据，没有 v3.0 数据集训练会直接报错，推理也无 checkpoint 可加载。

思考 1
若采集时收纳盒位置每次都被挪动，训练出的模型可能学会什么「歪本事」？这说明示范数据的哪类变量必须受控？
思考 2
行为克隆只模仿动作，不懂物理。请举一个本场景中「照猫画虎但会翻车」的风险点（提示：零件叠放、夹爪打滑），并说明可用什么手段缓解。
