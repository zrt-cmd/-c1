PROJECT OVERVIEW
项目总览：这条智能产线在做什么
一句话需求拆成四块拼图：任务链、语音入口、视觉/执行、安全底线。
一条完整的物流链
装货区 → 分拣区 → 流水线（定点停靠）→ 码垛区。装货靠视觉找位置，分拣靠人工教点位，码垛等光电传感器到位再下手——难度逐级递增。
语音是总入口
唤醒词（如"小飞小飞"）→ ASR 热词增强 → LLM 意图分类 → 固定话术回放与任务触发；R8 允许随时打断复位。
五节点 + 视觉协作
N1 语音、N2 调度、N-grasp 抓取、N-conveyor 流水线、N3 安全各司其职，N-vision 提供 AprilTag 位姿，复用底盘与机械臂底层。
安全优先于一切
R9：激光雷达前方 60° 扇区、20cm、持续 0.5s 判定危险 → 释放 6 舵机力矩；R9.1：雷达打断 > 语音打断。

LEARNING PATH
学习路径建议
先定需求，再写代码
EXP-01~03 是工程地基：拿不准需求就动手，后面每个"改一点参数重调两小时"都是它的利息。
单项功能逐个击破
EXP-04 语音、EXP-05 视觉、EXP-06 分拣、EXP-07 码垛逐一对通再串联——每个实验都有独立验证命令。
安全永远最后上也最先想
EXP-08 的急停逻辑要在每次实操前默念一遍：障碍对准雷达正前方、机械臂放安全位、手离抓取区。
用验证收口学习
EXP-09 的四链路 checklist 是全课程成绩单：能独立跑完"启动→任务→急停→清理"，才算真正通关。
PROJECT SETUP
环境与配置速查
开做之前对齐四件事：硬件在位、配置文件读懂、语音服务活着、启停命令记牢。
硬件清单
6 自由度总线舵机机械臂（舵机 ID 0-5）、差速底盘、麦克风阵列、单目摄像头（内参 fx=592.9 / fy=593.1 / cx=335.4 / cy=237.7）、
         激光雷达、流水线直流电机 M1 + GPIO17 光电传感器。做实验前逐一确认串口、GPIO17 导出与雷达 frame 就绪。
核心配置 eai_factory.yaml
mode（debug/production）双模式；vision：tag_id=3、tag_size=0.025、tag_family=tag36h11；
         grasp.tasks 三任务各自的 vision 开关与 observe/place 点位；pick_offset（+0.015 / -0.010 / +0.023）；
         safety：±30°、0.20m、0.5s；intents 意图映射与 wakeup_words 唤醒词。
语音侧服务
本地 LLM 为 Qwen3.5-0.8B（w4a16 量化约 500MB，监听 127.0.0.1:8080），起来后先
         curl http://127.0.0.1:8080/v1/models 自检；TTS 用 Matcha 声学模型 + vocos 声码器；
         8080 起不来是 EXP-04 / EXP-09 的头号失败点。
一键启停
ros2 launch 一条命令带 7 个 start_* 开关（start_base / viz / voice / vision / grasp / conveyor / radar，
         其中 radar 默认 false、独立于 start_base）；收工用 stop_eai_factory.sh 五段清理，直至打印"已全部清理干净"。
FAQ
常见疑问
前置要求是什么？
需要 ROS2 与视觉基础：会用 colcon 构建与 ros2 topic/service/launch 基本命令，了解相机成像与 TF 概念即可，
         课程内的需求工程、接口设计部分不要求任何嵌入式经验。
为什么分拣和码垛不用视觉？
yaml 中 sort / palletize 任务 vision=false，走人工示教定点（observe_pose / place_pose），稳定且可复现；
         只有装货 load 任务 vision=true，因为货物每次来的位置不同——这正是"能定点就定点，必须自适应才上视觉"的工程取舍。
急停触发后任务会丢吗？
危险判定触发后释放 6 舵机力矩、传送带停转，抓取与流水线进入受控中断；障碍离开并满足解除条件后自动恢复力矩并
         go_work 回位，但按 R9.1 任务需要手动重新触发，不会凭空续跑半截动作。
48 学时怎么排？
第 1 章 12 学时打地基（EXP-01~03），第 2 章 24 学时做功能（EXP-04~07），第 3 章 12 学时收口（EXP-08~09）；
         难度 ⭐ 的 EXP-01 可与理论课并行，⭐⭐⭐ 的 EXP-05 / 09 各留足整块实验时段，别拆开做。
