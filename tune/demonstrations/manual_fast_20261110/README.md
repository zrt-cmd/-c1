# G 到 C 的速度指令演示

2026-11-10，完整 Gazebo 车模及机械臂控制器启用，Nav2 未启动。
在扩为 45 cm 的地图上，从 G `(0.15, 1.70)` 到 C `(-1.80, 1.20)`。

运行脚本为 `tune/drive_manual_g_to_c.py`。路线为人工指定的 12 个拐点，
使用 Gazebo 真实车体位姿反馈校正直接发给 `/cmd_vel` 的速度，保持车头朝向。
这次演示能证明该路线在本次仿真中可行，不能作为自主导航或真车定位已通过的证据。

最高指令速度 0.20 m/s，仿真耗时 68.244 s，实际车体轨迹长度 10.1808 m。
终点为 `(-1.79994, 1.19425)`，离 C 约 5.8 mm。

- `telemetry.csv`：约 10 Hz 的仿真时间、真实车体位姿、速度指令、轮式里程计、激光最小距离及墙体几何余量。
- `route.json`：人工指定的路线点。
- `summary.json`：本次结果。

墙体余量按半长 0.18 m、半宽 0.16 m 的保守矩形包络计算，包含轮子碰撞球，
本次最小值 0.03995 m。没有物理接触传感器，因此不把该数值视作实际接触事件的检测结果。
激光最小距离可能包含车体自遮挡，不能直接当作车体离墙距离。
仿真轮子采用简化球面碰撞和方向摩擦，不能证明真实麦轮的动力学完全一致。
