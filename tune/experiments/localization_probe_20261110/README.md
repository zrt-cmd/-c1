# 定位与规划对照实验

使用完整仿真、地图服务器、AMCL 和 ThetaStar 规划器，未启动 Nav2 控制器。
配置见 `tune/config/localization_probe.yaml`，包含全向 AMCL 模型、3 cm 更新阈值、
0.08 m 的全局膨胀半径，以及当前 5 cm 栅格地图。

1. 显式提供 G、C 起终点请求规划，成功返回 138 个路径点，长度约 7.406 m。
2. 按固定 yaw=0、0.36 x 0.32 m 的车体包络对路径每约 5 mm 采样，
   1614 个样本中 1134 个与墙包络重叠，最深约 0.118 m（u_top）。
   这是本配置下的路径可跟踪性检查，不能推广为所有规划参数或所有转向方式必然失败。
3. 使用 AMCL 的 map->base TF 跟踪之前成功的人工参考路线，Gazebo 真值仅用于记录和离墙保护。
   行驶约 0.660 m、6.336 秒仿真时间后，首个拐点前触发 8 mm 几何余量保护停车。
   实际停车点约 `(0.8100, 1.7362)`，最大定位位置误差约 0.168 m。
4. 没有接触传感器，不能把几何保护视为物理碰撞检测。

下一步需要检查激光观测、TF、地图误差和 AMCL 匹配。
