# 激光、TF 和定位排查

这是对之前约 17 cm 误差结论的修正：旧跟踪程序每个控制周期只调用一次
`spin_once`，TF 回调会积压。该指标混入了读到旧 TF 的误差，不能全算作 AMCL 精度。
控制脚本已使用独立 TF 监听线程并在变换超过 0.15 秒时停车。

实测结果：

- 旧试验停车位置静态审计：TF 延迟 0.009 秒，真实位置误差 4.54 cm。
- 激光按真实位置、实际 TF 外参及世界墙体做射线距离对照：中位误差约 7 mm，95 分位约 20 mm。
  这不代表所有位置都没有自遮挡，但本次两个审计位置未发现整体外参错位。
- `fresh_tf/`：使用原 5 cm 地图，只跑首段；通过，最大位置误差 4.22 cm，采样 TF 最大延迟 0.019 秒。
- `map_1cm/`：仅细化同一墙体栅格，不改物理世界；全程尝试在第 8 段前保护停车。
  已完成 7 段、行驶 6.77 m，最大位置误差约 7.57 cm，采样 TF 最大延迟 0.020 秒。
  停车时包络几何余量 6.44 mm。不能据此声称发生了物理接触。
- `audit_1cm_stop.json`：停车后稳定 TF 位置误差 5.24 cm；激光中位误差 6.4 mm、95 分位 20.7 mm。
- 停车位置轮式里程计加 G 点偏移后与真实位置相差约 10 cm；轮式里程计仍存在全程累积漂移。
- 通过运行中 `ros2 param list /amcl` 确认，本版本不声明 `initial_cov_xx/yy/aa`。
  旧模板的这三个键没有设置 AMCL 初始化协方差。应在后续试验通过 `/initialpose` 消息传入明确协方差。

结果说明：TF 读取程序问题已修正，但仅细化地图并未解决定位精度问题。
根据用户的失败后先确认约定，车辆已停车，尚未继续修改观测模型或开展下一轮调参。
下一步建议检查明确初始化后的收敛，再调整激光似然模型；不要用真值反馈替代 AMCL 冒充通过。
