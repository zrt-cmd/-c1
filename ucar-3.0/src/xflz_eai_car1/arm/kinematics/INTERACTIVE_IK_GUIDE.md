# 交互式 IK 测试工具使用指南

## 功能

正是你想要的工作流程：

```
输入 TCP (x,y,z,pitch)
    ↓
解析法 IK 计算 → 显示 J1-J5 弧度值 + PWM 值 + FK 验证
    ↓
用户确认 (y/n)
    ↓
确认后通过 ROS2 发送到实物机械臂
```

## 使用方法

### 方式 1：直接运行（推荐先在无硬件下测试）

```bash
cd /home/iflytek/ros2_ws/src/xflz_robot_car1/arm/kinematics/kinematics
python3 interactive_ik_test.py
```

### 方式 2：编译后通过 ROS2 运行（实机控制）

```bash

cd /home/iflytek/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select car1_kinematics
source install/setup.bash

# 2. 先启动机械臂底层驱动（重要！）
ros2 launch car1_bringup bringup.launch.py

# 3. 另一个终端运行交互工具
ros2 run car1_kinematics interactive_ik_test
```

## 关键特性

### 1. 自动调整俯仰角（Auto Pitch）

如果你指定的俯仰角无法到达，工具会自动找最接近的可行俯仰角：

```
⚠ 自动调整俯仰角:
  实际俯仰角: 10.0°
  偏差: 10.0°
```

### 2. FK 验证

每次计算后自动验证精度（IK→FK 往返误差应 < 1.5mm）

### 3. 安全确认

发送前需要明确输入 `y` 确认，避免误操作

### 4. 运动时长控制

可设置运动时长（秒），控制机械臂运动速度，越大越慢越安全

## ROS2 消息格式

工具发送的消息：

**话题：** `/car1_base_driver/bus_servo/set_position`
**类型：** `car1_base_driver_msgs/ServosPosition`

```
duration: 2.0              # 运动时长（秒）
position:
  - {id: 0, position: 1500}   # 舵机ID0 → PWM
  - {id: 1, position: 1183}
  - {id: 2, position: 1412}
  - {id: 3, position: 2498}
  - {id: 4, position: 1500}
```

## 安全建议

### 首次实机测试

1. **先在空旷处测试**，确保机械臂周围无障碍
2. **使用较长运动时长**（如 3-5 秒），让机械臂慢速运动
3. **从安全位置开始**，先测试已知安全的目标点
4. **随时准备断电**，发现异常立即切断电源

### 推荐测试序列

```bash
# 1. 先回零位（所有 PWM 1500）
# 输入: x=0.055, y=0, z=0.59, pitch=90  (竖直向上)

# 2. 测试前方水平
# 输入: x=0.25, y=0, z=0.15, pitch=0

# 3. 测试抓取姿态（向下）
# 输入: x=0.20, y=0, z=0.10, pitch=-45
```

## 常见问题

### Q: 显示 "ROS2 未连接"
**A:** 工具会进入纯计算模式，可以查看 IK 结果但无法发送到实机。需要：
- `source install/setup.bash`
- 确保已编译 `car1_kinematics`

### Q: 发送后机械臂不动
**A:** 检查：
1. `bringup.launch.py` 是否已启动
2. 串口连接是否正常（`/dev/car1_stm32`）
3. 用 `ros2 topic echo /car1_base_driver/bus_servo/set_position` 确认消息已发出

### Q: 机械臂运动到错误位置
**A:** 可能是 PWM 转换参数与实物不符。检查：
- `transform.py` 中的 `SERVO_CONFIG`（方向、零位）
- `config.py` 中的几何参数

### Q: "Out of reach" 错误
**A:** 目标点超出工作空间（>252.3mm）。减小 x,y 坐标。
