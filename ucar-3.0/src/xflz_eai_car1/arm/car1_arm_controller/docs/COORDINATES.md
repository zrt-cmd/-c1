# 坐标系统约定

本文档定义 xflz_robot_car1 机械臂控制中使用的坐标系统和换算关系。

## 坐标系定义

### base_link（底盘坐标系）

- **原点位置**：4 个麦克纳姆轮的几何中心，在底盘板上
- **轴向定义**：
  - +X：车头方向
  - +Y：左侧方向
  - +Z：竖直向上
- **用途**：所有 IK 计算的输入坐标系（`/arm_controller/target_pose` 的 `frame_id: 'base_link'`）

### base_footprint（地面投影）

- **原点位置**：`base_link` 在地面的投影
- **用途**：导航、SLAM 使用

### arm_base_link（机械臂底座坐标系）

- **原点位置**：`arm_joint1` 旋转轴中心（机械臂底座旋转中心）
- **相对 base_link 的偏移**：
  - x = +46.6 mm（向车头方向）
  - y = 0 mm
  - z = +57.0 mm（向上）
- **用途**：讨论时使用（"机械臂底座前方 X cm"）

## 实测距离（2026-06-03）

| 起点 | 终点 | 距离 |
|------|------|------|
| base_link | 车头 | **188.68 mm** |
| arm_base_link | 车头 | **142.06 mm** |

验证：188.68 - 46.6 ≈ 142 mm ✓

## 坐标换算公式

### 从"车头前方 X cm"换算到 base_link 坐标

```
X_base = X_车头 + 188.68 mm
       = X_车头 + 0.18868 m
```

**示例**：
- 车头前方 20 cm 的物体 → `X_base = 0.20 + 0.18868 = 0.38868 m`

### 从"机械臂底座前方 Y cm"换算到 base_link 坐标

```
X_base = Y_arm_base + 46.6 mm
       = Y_arm_base + 0.0466 m
```

**示例**：
- 机械臂底座前方 15 cm → `X_base = 0.15 + 0.0466 = 0.1966 m`

### 从 base_link 坐标换算到"机械臂底座前方"

```
Y_arm_base = X_base - 0.0466 m
```

**示例**：
- IK 坐标 `x=0.22` → 机械臂底座前方 `0.22 - 0.0466 = 0.1734 m = 17.34 cm`

## 实际工作区域

根据扫描结果（`tools/scan_workspace.py`），机械臂在当前关节限位下的可达区域：

| pitch | X_base 范围 | Z 范围 | 备注 |
|-------|------------|--------|------|
| 0° (水平) | 无可达点 | — | 关节限位太紧 |
| 30° | 0.26~0.30 | 0.00~0.06 | 仅低矮区 6 个点 |
| 60° | 0.22~0.30 | 0.04~0.26 | 19 个点 |
| 90° (竖直向下) | 0.22~0.24 | 0.16~0.28 | 11 个点 |

**推荐工作区**（pitch=90°，末端竖直向下）：
- X_base: 0.22~0.24 m（机械臂底座前方 17~19 cm，车头前方 3~5 cm）
- Z: 0.16~0.28 m（离地面/桌面高度）
- Y: ±0.05 m（左右横向范围，受底座旋转限位 ±60° 约束）

## 注意事项

1. **IK 代码中的坐标**：始终使用 `base_link` 坐标系，不要混用
2. **讨论时的约定**：口头说"机械臂前方 X cm"时，指的是从 `arm_base_link` 算起
3. **Z 坐标基准**：所有高度都从 `base_link` 计算（底盘板高度），不是地面
4. **pitch 定义**：
   - pitch = 0：末端水平
   - pitch > 0：末端向下倾斜
   - pitch = π/2：末端竖直向下
